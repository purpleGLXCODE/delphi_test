# Тестовое задание — расчёт цены с НДС

Windows-приложение на Delphi 10.3 VCL.

## Алгоритм

Цена без НДС и цена с НДС хранятся в целых копейках. Для ставки НДС `p` допустимые пары должны удовлетворять:

`gross_cents = net_cents * (100 + p) / 100`

Чтобы обе цены были целым количеством копеек, `net_cents` должен быть кратен:

`100 / gcd(100, p)`

Отсюда минимальный шаг допустимой цены с НДС:

`(100 + p) / gcd(100, p)` копеек.

Алгоритм выбирает ближайшее целое кратное этому шагу к входной цене. Поэтому результат не требует округления до копеек и максимально близок к исходной цене. При точном равенстве расстояний выбирается большая цена.

## Примеры для ручной проверки

| Входная цена с НДС | НДС | Результат с НДС | Результат без НДС |
|---:|---:|---:|---:|
| 1000.00 | 20 | 1000.02 | 833.35 |
| 1000.00 | 0 | 1000.00 | 1000.00 |
| 100.00 | 25 | 100.00 | 80.00 |
| 1000.00 | 99 | 1000.97 | 503.00 |
| 0.00 | 20 | 0.00 | 0.00 |

Также проверить ввод с запятой и точкой, пустые и нечисловые поля, ставки -1 и 100, а также отрицательную цену.
